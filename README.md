# Hotelkönige

Ein 3D-Brettspiel für 2 bis 4 Hoteliers – im Browser, gegen den Computer, zu mehreren an einem Gerät oder online mit Raumcode.

- **Großes Brett:** https://korhankurtkenjiro.github.io/hotelkoenige/
- **Normales Brett:** https://korhankurtkenjiro.github.io/hotelkoenige/normal.html
- **Vorherige Version (Stand 31. Oktober 2026):** https://korhankurtkenjiro.github.io/hotelkoenige/alt/

Läuft am PC, auf dem Tablet und auf dem Handy (hoch und quer). Auf dem Handy am besten über „Zum Home-Bildschirm“ hinzufügen, dann startet es wie eine App im Vollbild. Beide Bretter und die vorherige Version können online miteinander spielen.

Enthält three.js (MIT-Lizenz) und PeerJS (MIT-Lizenz).
